# COS30045 Exercises 4.3–4.6 — Website with bar chart

A responsive D3 bar chart of TV models registered per brand (`js/main.js`): loads a CSV, binds data to bars, and sizes them with linear and band scales plus labels.

**Run:** `python3 -m http.server 8000` in this folder, then open <http://localhost:8000>.

**Data:** `data/tvBrandCount.csv`, TV models per brand, from `knime/2026 TV Data.knwf`.
